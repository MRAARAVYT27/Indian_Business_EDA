
# Indian Business EDA — Sales Analysis

## Project Overview
An exploratory data analysis project using the Sample Superstore dataset to understand sales, profit, product categories, regional performance, and customer behavior.

## Objectives
- Calculate key business KPIs.
- Analyze sales and profit by product category and region.
- Explore monthly sales trends.
- Identify top-performing products and customers.
- Investigate the relationship between discounts and profit.
- Create visualizations and a business insights report.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset
Sample Superstore sales dataset.

The dataset is used for educational analysis. Results describe this sample dataset and should not be interpreted as findings about the entire Indian business market.

## Project Files
- `Indian_Business_EDA.py` — analysis code
- `business_insights_report.txt` — generated business summary
- PNG files — saved charts

## How to Run
1. Install Python.
2. Install dependencies:
   `python -m pip install pandas numpy matplotlib seaborn`
3. Keep the dataset in the project directory with the expected filename.
4. Run:
   `python Indian_Business_EDA.py`
